# Flow Canvas

Flow Canvas is a reusable Next.js template for editable system diagrams and scripted visual simulations. The first version is under active development.

## Run locally

Use Node.js 22 and npm 10. Install the dependencies and start the app:

```bash
npm ci
npm run dev
```

Open `http://localhost:3000`. Run `npm run verify` before contributing.
